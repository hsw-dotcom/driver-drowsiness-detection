# 2023년 차량 시험 자료 검증 기록

> 출처: `3조 캡스톤 디자인 중간고사.pptx` (20장), `3조발표자료_최종발표.pptx` (8장), `정지중 테스트.mp4`, `주행중 테스트.mp4`, `야간 테스트.mp4`. 발표자료와 영상은 얼굴·개인정보가 포함될 수 있어 공개 저장소에 원본을 게시하지 않습니다.

## 프로젝트 참여와 역할
- 2023년 대학 캡스톤 프로젝트, 4인 조: 중간 발표 6번 슬라이드의 역할표에 **영상 팀 2인(김경욱, 손무현)**, **음성 팀 2인(노상운, 한상원)** 으로 구분되어 있습니다.
- 음성 팀의 주된 개발 흐름은 Google Cloud STT 실험, 마이크 녹음 및 TTS와의 연결, 문제 제시·음성 응답 검토입니다. 팀 내 개인별 코딩 범위는 원본만으로 독립 확인되지 않습니다.
- 영상 팀의 개발 흐름은 Picamera2/OpenCV, dlib 68점 얼굴 랜드마크, EAR 계산, 개인별 평균 보정과 눈 감김·고개 위치 조건입니다.

## 발표된 최종 3단계 개념(8장 중 3번 슬라이드)
1. 최초 졸음 감지: 스피커 경고음.
2. 재차 감지: 경고음 + 간단한 문제를 출제하고 마이크 응답을 처리; 오답일 경우 재시도.
3. 세 번째 감지: 경고음 + 데시벨 테스트, 마이크 음량 분석 결과가 설정한 최소 수준 이상이면 종료하는 구조.

**중요:** 위 흐름도는 발표된 최종 설계이며 세 단계가 모두 오류 없이 정상 동작했다는 검증은 아닙니다.

## 영상별 직접 관찰
- **정지중 테스트(약 1분 46초):** Raspberry Pi VNC 데스크톱과 카메라 앱 동시 표시. 평균 EAR, 눈 높이, 위험 판정, `detected`, `warning_count: 2` 및 `Listening...` 화면 확인. Geany에 열린 `test.py`(약 263줄)에서 감지 이후 `playy("detect.wav")`를 호출하는 부분과 `decibel.py`를 열어본 장면을 확인. 터미널에는 5초간 측정 안내와 계산된 평균 데시벨 값(예: 43.89 dB, 52.56 dB)이 나타납니다. 이는 **화면상 음성/소리 크기 측정 경로를 연계한 시험 증거**입니다. 당시 ALSA 관련 경고도 출력됩니다.
- **주행중 테스트(약 2분 42초):** 차량 내부 영상과 EAR·눈 위치 텍스트, `detected`/카운트 및 `Listening...`이 실행되는 장면. 주행 조건에서 추적을 시도한 영상 증거이나 정확도·운전 안전성의 정량 검증은 아닙니다.
- **야간 테스트(약 26초):** 어두운 차량 내부가 푸른 조명으로 비추어지는 환경에서 얼굴 및 눈 주변 시각화, EAR·눈 높이 수치 갱신이 확인됩니다. 모든 야간 조도에서 정상 동작한다는 근거는 아닙니다.

## 새롭게 밝혀진 코드 버전 차이
- GitHub의 `src/eye_detection/test.py`는 백업에서 찾은 초기/부분 코드입니다.
- 정지 중 영상의 Geany에는 더 긴 `/home/pi/project/test.py`(화면상 약 263줄), `test2.py`, `decibel.py`, `main.py`, `count_objects.py` 등이 보입니다.
- 그러나 해당 **차량 시험 당시의 통합 `test.py`, `decibel.py` 원본 파일은 현재 GitHub에 포함되어 있지 않습니다.** 따라서 화면에 나온 연동을 현재 저장소 소스만으로 재현할 수 없습니다.
- `Listening...` 표시와 데시벨 로그는 관찰됐지만 음성 답변의 정확한 STT 내용, 문제 정답 처리, 1~3단계의 모든 분기 성공 여부는 미확인입니다. 로그의 'dB'는 프로그램이 계산한 값이지 교정된 음압계 측정치로 간주할 수 없습니다.
- 영상과 사진 속 인물의 동의·초상권 문제가 있으므로 원본 미디어는 공개하지 않습니다.

## 프로젝트 경력 표기 권장
- “4인 팀 캡스톤에서 음성 팀으로 참여해 Google Cloud TTS/STT 기반 음성 문제·응답 기능을 개발·시험하고, 카메라 기반 졸음 감지와 연계한 차량 시연에 참여”
- 경고 성공률, 인식 정확도, 완벽한 3단계 경고 및 상용 수준 안정성은 근거가 없어 기재하지 않습니다.
