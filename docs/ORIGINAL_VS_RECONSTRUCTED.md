# 원본과 재구성 코드의 경계 — 2026-10-31

## 판정 우선순위

1. **최종 발표자료**: 발표된 목표 기능·처리 순서·성공/실패 분기를 정의한다. 발표자료는 소스 원본이 아니며 실행 성공을 증명하지 않는다.
2. **2023년 실제 소스 `src/`**: 구현된 함수·알고리즘을 확인하는 1차 증거. 실험 버전 간 차이는 원문 그대로 보존한다.
3. **개발 당시 질문·답변**: 발표자료 및 원본에 없는 구체적인 수치·호출 순서의 보조 증거.
4. **사용자 직접 확인**: 안경/선글라스 시험, 음성 답변 약 10초, 무제한 반복, 3단계 후 1단계 복귀 등 경험 사실.
5. **2026년 재구성**: 위 근거만으로는 코드 자체가 확보되지 않은 부분만 별도 구현. 완전한 2023년 원본이라고 주장하지 않는다.

## 원본 10개 — 절대로 재구성본과 혼합하지 않음

- 눈 감지: `src/eye_detection/test.py`, `src/eye_detection/test_v2.py`, `src/eye_detection/test3.py`
- 음성 실험: `src/voice_experiments/111.py`, `222.py`, `333.py`, `app.py`, `stt_test1.py`, `test1.py`, `test2.py`

`src/`에는 2023년 당시 코드 그대로 둡니다. 이름이 비슷하거나 버전이 오래되었다는 이유로 삭제·합성·수정하지 않습니다. 일부는 import 시 카메라/음성 장치를 사용하고, 일부는 파일 종료부 오류 등이 있으므로 **즉시 실행 가능한 통합 앱임을 의미하지 않습니다**.

## 원본만으로 최종발표 3단계 프로그램을 구성할 수 있는가?

**아니오.** 감지 알고리즘과 TTS/STT 실험 코드는 남아 있으나, 2023년 최종 시연의 더 긴 통합 `test.py`와 실사용 `decibel.py` 원본이 없습니다. `src/eye_detection/test_v2.py`는 `detected`를 화면에 표시할 뿐 음성 모듈을 호출하지 않습니다. `src/voice_experiments/test1.py`는 독립 실행형 실험으로 카메라 감지와 연결하는 함수 인터페이스가 아닙니다.

따라서 현재 `reconstruction/gaps/`는 **중복 기능을 재구현하지 않고 누락된 연결 개념만 보여 주는 교육·기록용 코드**입니다. 이 코드는 2023년 원본도 아니며, 카메라·마이크를 실제 연결한 실행 파일도 아닙니다. 과거의 더 큰 추정 통합 앱은 저장소 기본 브랜치에서 제외했으며 이전 커밋 이력에서만 확인할 수 있습니다.

## 사용자 확인 사항의 범위

- 얼굴형을 분류한 것이 **아니며**, 얼굴/눈 랜드마크를 찾은 다음 **눈의 EAR와 눈 위치**로 졸음 여부를 판단했습니다. 얼굴 검출 단계에 얼굴 영역을 사용하는 것과는 모순되지 않습니다.
- 안경·선글라스 상태에서도 **당시 실제 시험에서 작동했습니다**. 모든 선글라스의 차광도나 조명 조건에서 보장된다는 뜻은 아닙니다.
- 음성 반응 인식 구간은 **약 10초**입니다. 네트워크/API 요청 제한시간과 동일시하지 않습니다.
- 2단계 문제를 해결할 때까지, 3단계 음량 기준을 달성할 때까지 반복합니다. 임의 최대 횟수는 두지 않습니다.
- 다음 경고 단계는 1→2→3→1로 순환합니다.
