1. **최종 발표자료** `3조발표자료_최종발표(1).pptx` 작동원리 슬라이드(3번): 기능과 단계 성공·실패 분기의 최상위 기준
2. **2023년 원본**: 보존 브랜치 `archive/pre-final-cleanup/src/`의 실제 소스 10개 — 알고리즘의 1차 근거
3. **2023년 개발 대화**: 이후 변경 수치와 호출 순서 보조 근거
4. **사용자의 직접 확인**: 10초 안팎의 답변 인식, 오답·음량 미달 무제한 반복, 안경·선글라스 시연, 3→1 순환
5. **복원 추정**: 최종 시연 원본을 확보하지 못해 필요한 최소 연결·함수 구조 및 예외 처리

## 정확히 보존된 사실과 제한

- 2023년 원본 영상 감지 코드는 **얼굴 검출로 눈 랜드마크를 찾고 EAR·눈의 y좌표로 상태를 판단**합니다. 얼굴형 자체는 졸음 조건이 아닙니다.
- 당시 **안경·선글라스에서도 시연이 작동**했다는 것은 사용자 경험이며, 모든 사용자·렌즈·조명에 대한 검증은 아닙니다.
- `test_v2.py`: 약 30초 평균 측정, EAR 0.8, 10프레임, 눈높이+20픽셀. 후기 개발 대화: 3초 측정. 유지 코드에서는 **후기 3초**를 기본값으로 채택했습니다.
- 2단계에는 10초 안팎의 발화 인식·같은 문제 무한 반복이 필요합니다. 3단계는 음량 임계값 미달 시 반복하며, 단계는 1→2→3→1입니다. 네트워크 API 호출에 임의의 10초 제한을 부여하지 않습니다.
- 3단계 계산은 **원시 PCM RMS에 기준값 1을 둔 `20log10` 점수**이며, 물리적으로 보정한 데시벨 SPL이 아닙니다.
- 2023년 최종 시연의 `/home/pi/project/test.py`(약 263줄), 당시 `decibel.py`, WAV 파일, dlib 예측기 모델 자체는 보존된 코드 목록에서 누락되었습니다.
- 모듈 구조, `main.py` 진입점, 일부 예외 처리, 여러 얼굴 중 첫 번째를 선택하는 방식, Google STT의 녹음 후 단발 인식 방식은 **2026년 통합 연결을 위한 선택**이며 원본과 동일함이 확인되지 않습니다.
- 영상·음성 분석이 경고/응답 중 일시 중지된다는 점과 1초 무시 조건은 사용자 설명과 개발 대화의 근거가 있습니다.

## 보존 범위

**`main`은 최종 코드 버전 하나만 보입니다.** 구버전 소스와 단계별 임시 복원본은 `archive/pre-final-cleanup` 브랜치 및 Git 기록에 보존하며, 최종 코드와 한 폴더에 혼합하지 않았습니다. 지금의 최종 코드는 역사적 최종 실행 원본이 아닌 **최종 발표 기준 코드 복원본**입니다.
