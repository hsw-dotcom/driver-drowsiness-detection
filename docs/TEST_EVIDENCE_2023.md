# 2023년 차량 시험 증거 — 2026년 통합 복원본과의 구분

이 문서는 사용자 제출 2023년 중간·최종 발표자료와 정지 중/주행 중/야간 시험 영상을 토대로 작성한 **증거 설명**입니다. 영상에 등장한 사람의 얼굴과 사적인 환경이 포함될 수 있어 원본 영상은 공개 저장소에 올리지 않습니다.

## 자료별 확인 수준

| 자료 | 관찰된 사실 | 해당 자료만으로 증명되지 않는 것 |
|---|---|---|
| 중간 발표자료 | 4인 팀, 영상 팀(김경욱·손무현) / **음성 팀(노상운·한상원)** 역할 분담, EAR·TTS/STT 개발 방향 | 개인별 모든 함수 작성자, 통합 실기기 동작 |
| 최종 발표자료 | 1차 경고음 → 2차 산수 문제·음성 응답 → 3차 소리 크기 시험의 흐름 | 세 단계의 모든 분기·정확도·안전성 |
| 정지 중 테스트 영상 | Raspberry Pi/VNC, EAR·눈 위치·경고 횟수, `Listening...`, `decibel.py`의 소리 크기 계산 로그와 테스트 과정 | 모든 STT 정답 처리 및 3단계 전 구간의 완전한 성공 |
| 주행 중 테스트 영상 | 차량에서 얼굴·눈 관련 수치와 경고/음성 대기 화면 변화 | 운전 중 인지 부하 및 사고 예방 효과 |
| 야간 테스트 영상 | 야간 장면에서 얼굴·눈 주변 추적과 수치 표시 | 모든 조도에서의 정상 검출률 |

위 증거들은 **2023년 시연 시스템**에 관한 것입니다. 현재 `main.py` 및 `drowsiness/`는 2026년 복원 코드이며, 이 코드를 당시 차량에서 실행했다는 뜻이 아닙니다.

## 역할 구분

- **본인 참여 팀**: 음성 처리 팀 — Google Cloud STT/TTS, 문제 출제와 응답 판정, 소리 크기 측정 기능 개발·시험을 담당한 팀에 속했습니다.
- **다른 팀**: 얼굴·눈 랜드마크 인식, EAR 계산 등 영상 인식 기능.
- **공동 영역**: 통합 시험과 차량 시연. 개별 소스 파일의 단독 작성자 귀속은 원본만으로 독립 확정하지 않습니다.

## 기술 검증의 종류

1. **2023년 실제 화면 증거**: EAR, `detected`, `Listening...`, 평균 음량 계산 등.
2. **원본 실험 소스**: 보관 브랜치 `archive/pre-final-cleanup`의 `src/`에 일부 남아 있음.
3. **2026년 코드 시뮬레이션**: 단위 테스트·`--demo`로 상태 전환만 확인. 실제 카메라, 마이크, 네트워크 또는 차량 성능 검증이 아님.

## 복원 코드의 운전 안전성 주의

실제 운전 중 산수 문제에 답하거나 큰 소리를 내도록 요구하는 시스템은 **운전자 주의 분산을 초래할 수 있습니다**. 안전장치로 인증·검증한 결과물이 아니라 학교 캡스톤 연구 시제품의 기록이며 실제 주행 안전 기능으로 사용해서는 안 됩니다.

## 남은 결손

당시 차량 시연에 사용된 긴 `test.py` 및 `decibel.py` 원문은 확보되지 않았습니다. WAV 파일, dlib 68점 모델, Cloud 인증도 현재 저장소에는 포함하지 않습니다. 실제 전용 하드웨어가 없어 복원 프로그램의 재실행은 미검증입니다.
