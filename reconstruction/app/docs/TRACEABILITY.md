## 기존 복원본에서 바로잡은 부분

- **`quiz_record_seconds = 5` → `10`**. 10초는 음성 녹음 구간이지 Google Cloud API 요청의 네트워크 타임아웃이 아닙니다.
- **`loudness_max_attempts = 3` 삭제**. 최종 발표의 기준 미달 반복과 사용자 설명에 따라 무제한 시도.
- **퀴즈 실패 시 단계 종료 → 해결 전까지 같은 문제 반복**. 원본 음성 실험의 반복 구조를 기준으로 수정.
- **2/3단계 오류 시 다음 단계로 넘어감 → 미해결 상태 유지**. 정상 오답·음량 미달과 하드웨어/API 실패를 구분.
- **3단계 성공 후 1단계**를 테스트에서 검증.
- 경고음 기본 재생을 원본 음성 코드에 등장한 `playsound`에 맞춤(`aplay`은 선택 가능).

## 일치시킬 수 없는 부분

최종 차량 시연에 이용된 긴 통합 `test.py`, 별도 `decibel.py`의 **원본 파일 전체는 확보하지 못했습니다**. 확인된 `src/` 원본은 수정하지 않았고, 이번 통합본은 최종 발표 자료에 가장 가깝게 조합한 *복원 추정 코드*입니다. 특히 TTS 결과 안내 WAV(`result1.wav` 등)의 최종 시연 파일 종류, STT 단발·실시간 스트리밍 최종 선택은 단정하지 않습니다.
