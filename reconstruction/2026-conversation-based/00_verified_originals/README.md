# 확인된 원본 소스 (수정하지 않음)

이 폴더의 4개 Python 파일은 사용자 파일 라이브러리에서 직접 확보한 소스의 바이트 복사본입니다.
파일명도 원본을 보존했습니다. 테스트 단계·시연 단계·최종 통합 단계 중 어느 시점의 코드인지는 파일별 추가 검증이 필요합니다.

- `test_v2.py`: Picamera2 + dlib + EAR + 초기 30초 기준값 + 시각적 졸음 판정. 원본 코드 끝의 `cap.release()`는 정의되지 않은 변수를 참조합니다.
- `111.py`: PyAudio를 이용해 3초 음성을 `user_response.wav`로 저장.
- `222.py`: Google Cloud TTS/STT 기반 수학 문제를 생성하고 녹음·정답 판정. 실행 시 외부 API 인증·과금이 발생할 수 있습니다.
- `333.py`: Google Cloud Streaming Speech-to-Text 마이크 스트리밍 실험.

원본 4개가 곧 2023년 완성형 제품의 전체 소스라는 의미는 아닙니다.
