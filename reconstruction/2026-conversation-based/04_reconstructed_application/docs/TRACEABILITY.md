## 충돌 기록

- 2023-11-11: 초기 측정 약 30초, 1~2회 warning.wav, 3회 danger.wav→test1.py 실행을 시도.
- 2023-11-22: 초기 측정 3초, 1회 wa.wav→warning.wav, 2회 da.wav→danger.wav→test2.py, 3회 da.wav→decibel.wav→decibel.py로 확장. **후기 설정을 통합본 기본값으로 채택**.
- `111.py`(PyAudio 녹음), `222.py`(TTS/STT 단발), `333.py`(Google STT 스트리밍)은 확보된 별개 실험 원본. **이 원본 파일을 최종 통합본이라고 주장하지 않음**.
- 원본 WAV, 전체 프로젝트 `test.py`, `test1.py`, `test2.py`, `decibel.py` 원문과 모델은 여기서 추출 불가. 파일명을 동일하게 쓴 통합 어댑터는 새로 작성한 것입니다.

## 실행 확인 범위

1. Python 정적 문법 검사 (Python 3)
2. 로직 단위 테스트 (카메라/마이크/클라우드 의존성 대역 사용)
3. 통합 dry-run: `python main.py --demo`
4. 실제 카메라/오디오/Google API/운전 중 감지 정확도: 검증하지 않음

추가 확인: 경고용 WAV가 없으면 실제 경고 단계는 로그에 오류를 남기고 종료되며, 소리 없이 정상 동작했다고 표시하지 않습니다.
